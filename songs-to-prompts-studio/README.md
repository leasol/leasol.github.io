# סטודיו שירים לפרומפטים

ממשק Flask מקומי לעריכת ספריית השירים והפרומפטים. הנתונים המקוריים שהועתקו מהפרויקט הקודם נמצאים ב־`data/songs.json` (2,408 שירים).

## הפעלה

```bash
cd songs-to-prompts-studio
python3 server.py
```

פותחים בדפדפן: `http://127.0.0.1:8766`

הסטודיו מאפשר חיפוש, סינון לפי אמן/מצב פרומפט, עריכת שירים, הוספת שירים, וייבוא/ייצוא מלא של הנתונים. כל שמירה מעדכנת את `data/songs.json`; `data/songs.seed.json` הוא גיבוי בלתי-שונה של הייבוא הראשוני.
